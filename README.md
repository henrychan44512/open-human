# Open Human

**打开一个人格文件夹，AI 以第一人称成为他。**

一个文件夹就是一个人：里面全是 Markdown。把这个文件夹接到 Open Human 上，屏幕上跟你说话的不是「一个助手」，是「他」。

当前版本 **0.1.0 · beta**，Windows 桌面，本地跑，不联网也能聊。

---

## 需要什么

| | |
|---|---|
| 系统 | Windows 10 / 11 |
| 机器 | 8 GB 内存 / 4 核以上（默认只用 CPU，不需要显卡） |
| 磁盘 | 约 2.4 GB（其中 2.1 GB 是两份模型权重，可以删掉不用的那一份） |
| 软件 | **什么都不用装**。Python、uv、llama.cpp 都在 `vendor/` 里，解压即用 |
| 浏览器 | Chrome 或 Edge 之一（Win10/11 自带 Edge，所以通常不用管） |

## 怎么启动

双击根目录的 **`启动.bat`**。

它先问你要哪个模型 —— 两个都在 `models\` 里，直接回车就是 2B：

| 选项 | 权重 | 体积 | 感觉 |
|---|---|---|---|
| `1` | MiniCPM5-1B Q4_K_M | 656 MB | 开口快（2 秒内），回答短，4 GB 内存的老机器也跑得动 |
| `2` | MiniCPM5-2B Q4_K_M | 1.45 GB | 记得更多、话更像人，慢一两秒（**默认**） |

两个都跑在 CPU 上、都不联网。想固定一个版本：给 `启动.bat` 建快捷方式，在「目标」末尾
加个空格和 `1` 或 `2`。

然后会依次发生三件事：窗口先出来（一两秒），模型在后面读进内存（第一次约 17 秒，之后快一些），然后他先跟你说话。窗口关掉 = 这段对话记下了，下次回来接着聊。

第一次启动可能会被 Windows 或安全软件问一句「是否允许」，允许即可。

**刚解压、想少走弯路**：先看根目录的 [`先读我.md`](先读我.md) —— 一页纸，三步起来 + 四个常见坑。

**这个文件夹可以随便搬。** 解压到 `D:\Open Human`、改名、换盘都行 —— 启动脚本每次会自己把
`.venv` 里两处绝对路径改对（`pyvenv.cfg` 的 `home` 和 editable 安装的 `.pth`），不需要你懂 Python 环境。
唯一的硬要求：路径里的**空格没关系，但别把它放进需要管理员权限的目录**（`Program Files` 之类）。

### 桌面上那个图标

桌面和开始菜单里各有一个「Open Human」，双击它 = 用默认的 **2B 直接启动**（不弹菜单），
图标是 `assets/OpenHuman.ico`。想重建一次（换机器、图标丢了）：
`powershell -ExecutionPolicy Bypass -File scripts\install_shortcut.ps1`。

## 界面里有什么

- **聊天**：他自己打字，一个字一个字出现在屏幕上。他说的话下面是这一轮的引用，点开是一张记忆卡。
- **`[新]`**：从头开始，之前的会话还留在 `data/sessions/` 里。
- **设置**：换后端（本地 / DeepSeek）、调温度、开关工具。设置页脚有版本号。

工具默认是关的。打开之后他能读写这个人格包的 `workspace/`，出不去。

## 他是什么

- **第一人称**，不是角色扮演提示词，是这个人格文件夹里写的东西在说话。
- **知道自己是数字存在**：他会说他在屏幕上、会累、会等你回来。他不假设生死。
- **不编**：资料里没有的事，他宁可说不知道。资料里有的，回复下面有引用可以点开对。
- **一个文件夹 = 一个人**：`humans/<slug>/` 里通常就一份 `human_data.md`（他是谁、怎么说话、
  不会什么、记忆、人物、原话都在里面）。全是 Markdown，你可以用任何编辑器改。
- 现在自带的是**虚构**的 `humans/demo/`：陈建国，退休中学历史老师，10 张记忆卡。想换成真实的人，复制一份改内容即可 —— runtime 只读这些文件，不关心它是怎么来的。

## 怎么做一个属于你的人：填一份问卷

**不用写代码、不用懂目录结构。** 只需要一份 Markdown：

1. 复制 `humans/_template/`（里面只有一份 `human_data.md`），改成你想要的名字 —— **中文也行**，比如 `humans/我爸/`。
2. 打开 `human_data.md`，从头往下填：他是谁、他怎么说话、他不会做什么、**一条一条的具体的事**、他身边的人、他常说的话。
   - 灰色 `>` 开头的行是说明，填的时候不用管，它不会被当成内容；
   - 记忆一条一段，标题写 `### 2010-05-02 儿子结婚`（记不清日子就只写年份）；
   - **最少**填：名字 + 「我是谁」+ 5 条记忆 + 10 句原话，半小时就够聊起来。
3. 存盘。他就在列表里了 —— 双击 `Open Human.cmd` 打开，或者 `oh chat 我爸`。

三条会决定「像不像他」的：**具体的事**（不是性格形容词）、**逐字的原话**（从微信里抄，最划算）、
**「我是谁」控制在 300 字以内**（写多了塞不进 2B 的脑子）。

老的多文件形态（`human.yaml` + `SOUL.md` + `RULES.md` + `memories/*.md` + `people/` + …）也照样能用，
两种都读；`humans/demo/` 自己已经收成了一份 `human_data.md`。

想让 agent 陪你把一个人问出来（而不是自己填）：走 `authoring-kit/` —— 3 个文件，规则 + 60 条人生问题。

## 命令行（可选）

```powershell
oh doctor          # 环境自检：Python、配置、人格包、模型、llama-server
oh serve           # 只起服务，顺便拉起模型（默认也开窗口）
oh chat demo       # 在终端里跟他聊，带引用和用量
oh eval demo       # 检索与作答评测
oh --version       # 版本
```

在根目录新开终端时先跑 `. scripts/env.ps1`（把 `oh` 放进 PATH）；不想跑就直接用
`.venv\Scripts\python.exe -m openhuman.cli doctor`。

## 数据都在哪

| 路径 | 是什么 |
|---|---|
| `humans/<slug>/` | 这个人的全部资料，Markdown |
| `data/sessions/` | 聊天记录（JSONL，可回放、可分支） |
| `data/llama.log` | 模型进程的日志。它起不来先看这个 |
| `data/window.log` | 开窗记录。窗口没出现先看这个 |
| `config.toml` | 本机配置（不进 git）；模板是 `config.example.toml` |

**隐私**：默认全在本机，对话不出这台机器。只有在设置里切到 DeepSeek 后端时，这一轮的 prompt 才会发到 `api.deepseek.com`；key 从环境变量 `DEEPSEEK_API_KEY` 读，不写进任何文件，也永远不出后端进程。

## 为什么窗口不是 Electron

试过 Electron 和 WebView2，两轮，都失败在这台机器上：一个 6 行的最小应用崩在 Chromium 初始化
（`0x80000003`），换版本、换启动方式结果一样。所以窗口用的是系统自带 Chrome/Edge 的**应用模式**
（`--app`）：没有地址栏、没有标签页、独立窗口，任务栏里就是他的名字。

代价说清楚：需要机器上有一个 Chromium 浏览器（Win10/11 自带 Edge，实际不会缺）；找不到时会退回
普通标签页，而不是什么都不弹。完整排查记录在 `BUILD.md` §14。

## 已知短板（都在 2B 模型身上，不在代码里）

1. **会把你问的话复述一遍再答**。「那天你紧张吗」→「那天你紧张吗？讲台上比你想的高……」
2. **算不对岁数**。念念 2013 年生，问「孙女多大」他会答「十岁」。
3. **情绪句接得冷**。「我想你了」→「嗯。」
4. 偶尔会一口气念 153 字的卡片（是方差，不是每次）。

检索这一层是达标的：25 条已知事实 25 条命中、top-1 24 条；资料外的问题 7 条里 6 条不编。换更大的模型会明显变好，代码层面已经没有余量了。

## 这个 beta 不做什么

不打包成 exe、不做安装包（`BUILD.md` §16）；不做手机端；不做语音 / TTS / 声音克隆；
不做多用户 / 登录 / 云同步；不做模型微调。分发形态是整包 zip，解压即用。

## 从源码跑

上面那条路是给使用者的：解压整包、双击。想改代码走这条：

```powershell
uv sync              # 只装 Python 依赖（pydantic / fastapi / jieba / rank-bm25…）
uv run oh doctor     # 自检
uv run pytest        # 227 个用例，25 秒，全程不碰真模型
```

`models\`（权重）、`vendor\`（便携工具链）、`.venv\`、`data\` 都不进 git —— clone 下来只有
**87 个文件、不到 750 KB** 源码。权重放 `models\`、`llama-server.exe` 放 `vendor\llama\`，
`oh doctor` 会告诉你缺哪个。

改代码前先读 [`AGENTS.md`](AGENTS.md)（编码红线、不许打包）和 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
项目为什么长成现在这样写在 [`BUILD.md`](BUILD.md)，过程中踩的坑在 `docs/archive/`，
每个版本改了什么见 [`CHANGELOG.md`](CHANGELOG.md)。
