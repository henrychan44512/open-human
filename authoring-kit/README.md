# Human Pack Authoring Kit

> 用任意能读写的 AI agent，把一个人的资料做成**一份** `human_data.md`。
> 它不运行聊天 —— 聊天是 `open_human` app 的事。

---

## 0. 两个模型，两条流水线

**作者阶段（本套件）**：你的 agent + 它自己的大模型。访谈、看图、抽取、写字。

**运行阶段（`open_human` app）**：本地 MiniCPM5-2B 读那份文件，以第一人称说话。

两者只通过一份 Markdown 交接。作者阶段用最聪明的模型，运行阶段用最小的本地模型。

---

## 1. 只有 3 个文件

```
authoring-kit/
├── README.md     你正在看的
├── AGENTS.md     给 agent 的规则
└── QUESTIONS.md  60 条人生问题
```

没有脚本、没有数据库、没有按工具定制的分支。

---

## 2. 成品长什么样

看两处就够，**不要自己发明结构**：

- `humans/_template/human_data.md` —— 空表单；
- `humans/demo/human_data.md` —— 填好的样子。

小节固定七个：`基本` / `我是谁` / `我怎么说话` / `我不会` / `记忆` / `人物` / `我常说的话`。
runtime 只认这一份文件。

---

## 3. 怎么用

**文件模式**（agent 能读写文件夹）

1. 把 `AGENTS.md` 和 `QUESTIONS.md` 交给它；
2. 让它建 `humans/<名字>/human_data.md`，照 `_template` 的小节往里填；
3. 一次一题，每 5 题读回草稿确认。

**对话模式**（只能贴文本）

1. 把 `AGENTS.md` + `QUESTIONS.md` 的相关段落贴给它；
2. 它输出 Markdown，你粘进 `human_data.md`。

---

## 4. 质量原则

1. 不编日期、人名、地点；不知道就写「记不清」。
2. 原话加引号，逐字，不改写、不润色。
3. 写事不写性格：「我脾气不好」没用，「那次我把碗摔了」有用。
4. 每 5 题读回草稿。
5. 本人确认后才算封版。
6. 纯后勤（「今晚吃什么」）丢掉。

---

## 5. 不做的事

不做语音访谈；不做模型训练 / 微调；不做聊天运行时；
不替本人做心理治疗、诊断或人生建议。

---

## 6. 目标

**最少**：名字 +「我是谁」+ 5 条记忆 + 10 句原话 —— 半小时能聊起来。

- 「我是谁」≤ 300 字，「我怎么说话」≤ 200 字；
- 记忆一条 3–6 行，写清在哪、还有谁、那天发生了什么、你说了什么；
- 原话 20 句就很够，抄微信里真说过的，不改写。
